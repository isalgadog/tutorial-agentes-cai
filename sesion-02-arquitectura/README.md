# Sesión 2. Infraestructura y arquitectura para un agente de IA de atención a clientes

Esta sesión toma las decisiones de producto de la sesión 1 y las traduce a una arquitectura mínima viable para operar un agente de atención a clientes con bajo costo y baja complejidad.

## Contenido

- `explicacion.md`: resumen conceptual de la sesión
- `challenge/`: reto práctico basado en configuración de arquitectura

## Objetivo de la sesión

Que la audiencia entienda cómo aterrizar un agente en componentes concretos:

- frontend
- backend u orquestador
- modelo
- herramientas
- memoria
- datos
- flujos entre componentes
