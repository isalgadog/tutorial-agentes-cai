# Prerrequisitos del curso

Este archivo resume qué necesita una persona participante para poder seguir el tutorial y ejecutar los retos de forma práctica.

## Objetivo

Mantener la barrera de entrada baja.
La idea del curso es que se pueda trabajar con una configuración ligera, sin infraestructura pesada ni demasiadas dependencias adicionales.

## Requisitos mínimos

### 1. OpenClaw instalado y funcionando
Se espera que la persona pueda usar OpenClaw en su máquina.

Idealmente debe poder:
- abrir una sesión
- leer y editar archivos
- trabajar dentro de un workspace local

### 2. Acceso a un modelo asistente
El curso está pensado para funcionar con una combinación simple como:
- OpenClaw + Codex
- OpenClaw + Gemini

La persona no necesita múltiples proveedores a la vez.
Con uno funcional es suficiente para seguir el curso.

### 3. Editor de código o archivos
Se recomienda contar con un editor como:
- Visual Studio Code
- Cursor
- cualquier editor de texto cómodo

La mayoría de los retos consisten en modificar:
- archivos YAML
- archivos JSON
- archivos Markdown

### 4. Git instalado
No es indispensable para leer el curso, pero sí muy recomendable para:
- versionar cambios
- comparar soluciones
- guardar avances por sesión

### 5. Conocimiento técnico básico
No hace falta experiencia profunda en IA o MLOps.
Sí conviene tener nociones básicas de:
- productos digitales
- APIs o sistemas web
- archivos de configuración
- flujos entre frontend, backend y datos

## Recomendado, no obligatorio

### 1. VS Code con acceso al repo local
Ayuda para recorrer los materiales del curso y editar los archivos de reto.

### 2. Familiaridad básica con OpenClaw
Por ejemplo:
- abrir el workspace
- navegar sesiones
- editar archivos
- trabajar con repositorios locales

### 3. Una cuenta operativa del modelo elegido
Si usarán Codex o Gemini, conviene llegar con la cuenta ya configurada para no perder tiempo en setup durante la sesión.

## No requerido

Este curso no requiere, de inicio:
- Docker
- Kubernetes
- bases de datos complejas
- despliegue cloud
- sistemas de colas
- observabilidad enterprise
- un CRM real conectado
- integraciones productivas con sistemas externos

## Setup sugerido antes de comenzar

Antes de iniciar el curso, idealmente cada participante debería haber validado esto:

- OpenClaw abre correctamente
- puede acceder al workspace del curso
- puede editar archivos `.md`, `.json` y `.yml`
- tiene disponible al menos un asistente o modelo para apoyarse
- puede abrir el repositorio en su editor local

## Checklist rápido

- [ ] Tengo OpenClaw instalado y funcionando
- [ ] Tengo acceso a Codex, Gemini o equivalente
- [ ] Puedo abrir el repositorio localmente
- [ ] Puedo editar archivos YAML, JSON y Markdown
- [ ] Tengo un editor de texto o IDE listo
- [ ] Tengo Git instalado, de preferencia

## Nota para facilitación

Si este tutorial se va a impartir en taller, conviene verificar el setup antes de la primera sesión para no perder tiempo de clase en instalación o conexión.
