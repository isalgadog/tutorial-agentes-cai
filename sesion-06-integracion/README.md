# Sesión 6. Integración, tradeoffs y operating model para un agente de IA de atención a clientes

Esta sesión conecta las decisiones de producto, arquitectura, seguridad, observabilidad y experiencia en una visión integrada del agente como sistema operable.

## Contenido

- `explicacion.md`: resumen conceptual de la sesión
- `challenge/`: reto práctico integrador basado en decisiones finales de diseño

## Objetivo de la sesión

Que la audiencia entienda cómo tomar decisiones finales de integración y operación:

- qué se deja dentro o fuera del agente
- qué tradeoffs se asumen
- cómo se prepara una primera versión operable
- cómo se gobierna su evolución
