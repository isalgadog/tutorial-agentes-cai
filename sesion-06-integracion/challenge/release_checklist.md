# Checklist de salida

- El alcance de la versión 1 está claramente delimitado.
- Las capacidades excluidas están documentadas.
- Las acciones sensibles están bloqueadas o controladas.
- El flujo de handoff está definido y probado.
- Existen métricas mínimas de producto, riesgo y sistema.
- Hay reglas básicas de revisión manual.
- La experiencia del usuario comunica estados y límites.
- Se revisó una línea base mínima de accesibilidad.
- Existe ownership claro para producto, operación y riesgo.
- Los tradeoffs principales están documentados.
