# Checklist básica de accesibilidad

- El foco visible está presente en todos los controles interactivos.
- La interfaz se puede recorrer por teclado.
- Los estados del sistema se comunican con texto claro.
- Los mensajes de error explican el siguiente paso.
- El contraste es suficiente para lectura prolongada.
- No se depende solo del color para comunicar estado.
- Las confirmaciones sensibles son entendibles.
- La interfaz evita animaciones innecesarias o permite reducirlas.
- Los cambios importantes de estado son compatibles con lectores de pantalla.
