# tutorial-agentes-cai

Tutorial para diseñar y prototipar agentes de IA para atención a clientes, con un enfoque práctico y de bajo costo usando OpenClaw junto con asistentes como Codex o Gemini.

## Objetivo del curso

Este repositorio reunirá una serie de sesiones para explorar, de forma progresiva, cómo diseñar un agente de IA de atención a clientes desde varias dimensiones:

1. Producto y especificación
2. Infraestructura y arquitectura
3. Seguridad y guardrails
4. Monitoreo y observabilidad
5. Frontend y accesibilidad

La idea es trabajar con retos guiados y artefactos simples de configuración para que las personas participantes puedan avanzar sin necesitar una infraestructura compleja ni software adicional pesado.
